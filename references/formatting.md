# Основания оформления и результаты разбора

Проверен репозиторий https://github.com/AliZeit/SEROVVVV, коммит `f1e23721e403a7b79a4add4f3ed1f0136112c6ae`.

Основные источники:

- `ЛР-1. Ткаченко.odt` — образец отчёта по созданию скриптов установки и удаления ПО в Windows и RedOS. Это **другая тема**, не установка ROSA из каталога `lab1`.
- `Стандарт_студенческие_работы_общие_положения_и_правила_оформления.pdf` — СТАНДАРТ 01-2023 Университета «Сириус», утверждён приказом от 25.01.2023 № 13/3-ОД-У.
- `lab1/TASK.MD` — описание 22 шагов установки ROSA Linux. Для демонстрации использованы только первые три шага и снимки.

PDF содержит 48 сканированных страниц, а не извлекаемый текстовый слой. Выполнено OCR всех страниц; ключевые параметры полей, шрифта и интервала дополнительно сверены визуально со страницей 20 PDF. Номера ниже — **физические страницы PDF**; внутренний номер листа стандарта обычно на два меньше. При спорной формулировке проверяйте оригинальное изображение страницы, а не OCR.

## Что взято из образца

Композиция титула: университет → подразделение/направление → тема → вид работы и дисциплина → студент → руководитель/оценка → место и год. Структура содержания с введением, основной частью, контрольными вопросами и источниками.

Новые страницы для основных разделов и компактная компоновка реквизитов титула — настройки этого шаблона. Не каждая такая настройка является отдельным обязательным требованием стандарта.

## Что не скопировано вслепую

- В образце подписи встречаются в виде `Рисунок 1. Скрипт`, а стандарт задаёт нумерацию в пределах раздела. В генераторе используется `Рисунок 1.1 — …`.
- В XML образца есть несколько разных макетов страницы. Поэтому его набор стилей не импортируется целиком: поля заданы явно по п. 5.1.3.
- При извлечении текста из ODT обнаруживаются повторяющиеся тексты отдельных подписей; это само по себе не доказывает визуальное дублирование. Новый генератор создаёт одну подпись на рисунок.
- В образце указан адрес видео с фрагментом `example-bash-bat-automation`. Он не использован как подтверждённый библиографический источник.
- Утверждения образца о полном удалении ПО, всех зависимостей и конфигураций нельзя переносить в новый отчёт без проверок.
- ФИО, группа, специальность, дисциплина и даты автора не подставляются за пользователя.
- В шаблон добавлено явное заключение; контрольные вопросы оставлены удаляемым разделом.

## Ограничения соответствия

Генератор реализует основные параметры оформления обычного текста, заголовков, изображений и небольших таблиц, но не является сертифицированным валидатором стандарта. Обязательная ручная проверка остаётся для содержания, титула, библиографии, переносов, сложных объектов и специальных требований преподавателя.

Проверка в этой среде выполнена LibreOffice с подстановкой Liberation Serif вместо отсутствующего Times New Roman. Название требуемого шрифта сохранено в стилях ODT; переносы и число страниц следует повторно проверить на целевом компьютере.
